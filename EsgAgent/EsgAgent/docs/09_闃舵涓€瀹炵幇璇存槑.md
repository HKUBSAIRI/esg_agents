## 2. 数据流

```text
PDF 文件
  → IngestService：大小/页数/%PDF 头校验，sha256，原件不可变存储，ReportRef
  → SkillLoader.resolve(common→行业→13 指标)，PromptRegistry.render(v1)
  → QwenPDFClient：整份 PDF（单次调用，禁止切页）+ Skill+Prompt → JSON
  → ExtractionAgent：解析(必要时一次修复) → 页码/指标/状态校验 → ID 重映射 → ExtractionBatch
  → export：按 GROUP/报告年度/置信度选候选 → 单位归一化（展示用） → 15 列 CSV + 明细 CSV
```

## 3. 关键实现决策

1. **单次整份 PDF**：每次提取只发一份完整 PDF，不切页；输出截断（`finish_reason=length`）直接失败，不把残缺候选当全集。
2. **PDF 传输**：本地对象存储无公网 URL，默认走 `file_data`（base64）。DashScope 兼容模式对单个 JSON 字符串有 **28,000,000 字符**上限，27MB PDF 的 base64（36MB）会 400；此时用 `scripts/oss_signed_url.py` 上传 OSS 取短时签名 URL，走官方首选的 `file_url`（`--pdf-url`）。本次华润饮料即用该路径，青岛啤酒 base64 直传。
3. **模型输出容错**：坏 JSON 先做一次 `repair_json`（纯文本，不带 PDF）；仍失败保存原始响应（`data/batches/<report_id>.raw.json`）并抛 `MODEL_BAD_JSON` 转人工。
4. **ID 与幂等**：模型输出 `ev_001/ca_001` 等临时 ID，Python 统一重映射为 UUIDv7 前缀 ID，并注入 `report_id/company_id/report_year`；批次按 `report_id` 缓存，`--force` 重跑。
5. **不硬归类**：`UNKNOWN` 时 `metric_id` 必须为 null；未登记指标降级为 UNKNOWN 并打 `UNKNOWN_METRIC`；页码越界证据标 `UNVERIFIED` 且候选转 `NEEDS_REVIEW`。
6. **归一化边界**：`normalized_value` 不由模型写入；当前仅用于候选导出展示（万吨→m³、亿元→百万元、吨→t、%）。正式事实归一化按文档留在审核通过后的发布事务里。
7. **币种规则**（本轮调整一次）：营业收入币种不明不阻断指标归类；`元/万元/亿元` 按中文内地报告惯例记 CNY，`港元/美元` 按原文；完全无线索时仍可 CLASSIFIED 但打 `CURRENCY_UNCLEAR`。
8. **大 PDF 分块并行**：分块之间用 `ThreadPoolExecutor` 并发执行（`--concurrency` / `EXTRACT_CHUNK_CONCURRENCY`，默认 3、上限 4），按块顺序合并结果，保证与串行一致；某块失败不落半成品批次，已完成块的原始响应保留；并发触发可重试错误（429/超时/瞬时 APIError）时，只重跑失败块一次，且立即重跑、与其他块并行，不阻塞整体。
9. **计量**：适配器记录首 token 延迟（`first_token_ms`），提取结束记录 `elapsed_ms`、各块 `chunk_latencies_ms`、实际并发数，用于区分“平台解析+预填”与“生成”耗时。**思考模式始终开启**，不做关闭/减弱。

## 6. 待人工确认项（建议）

1. **营业收入（唯一未对齐项）**：标准答案 00291=37985.000、02460=11002.111、00168=32473.494 百万元（3 位小数），但三份 ESG PDF 都没有该精度数据——华润饮料/华润啤酒未披露营收，青岛啤酒只给“324.73 亿元”（两位小数，换算 32,473.000）。需把**年报/财务主数据**作为第二数据源接入（Excel/CSV 或年报 PDF），否则该列无法达到标准答案精度。当前输出：00291/02460=N/A、00168=32473.000。
2. **水循环利用率公式**：标准答案采用 `循环利用水量 /（总取水量 + 循环利用水量）`（02460：181.99/(1,366.20+181.99)=11.7550%），已按此实现并标注“推算”；若业务改用 `循环利用水量/总取水量`，结果为 13.32%。需确认口径。
3. **青岛啤酒“用水量→总取水量”**：已按标准答案口径归为取水量（`DEFINITION_INFERRED`），非报告明示口径；若后续要求“口径不明即 UNKNOWN”，需回退该规则。
