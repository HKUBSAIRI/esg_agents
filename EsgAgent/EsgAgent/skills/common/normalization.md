# 单位识别与登记规则

本规则只解决“**单位怎么说、怎么登记**”，不解决“单位怎么换算”。**换算由 Python 的
normalizer 在审核通过后执行，模型与 Skill 不得自行换算、四舍五入或改写原值。**

## 1. 基本原则

- `raw_value` 只放原文字符串，保留千分位、小数位、正负号，不带单位；
- `unit` 放原文单位文本（逐字），如 `万吨`、`万立方米`、`立方米`、`吨`、`%`、`吨/吨`；
- 单位出现在表头“单位”列或脚注时，`unit_header` 填原文单位，`unit` 仍填该指标实际单位；
- 中英文/符号混用照抄：`m³` 不写成 `m3`，`m3` 也不改成 `m³`；`CODcr`、`NH3-N` 原样保留；
- 原文单位与数值连写时，`raw_value` 只取数字部分：`"1,366.20 万吨"` → `raw_value="1,366.20"`，
  `unit="万吨"`；
- 单位缺失或不可辨认：`ambiguity_flags` 加 `UNIT_MISSING` / `UNIT_UNCERTAIN`，**不猜测**；
  有歧义时 `NEEDS_REVIEW`。

## 2. 体积单位（水量）

登记原文写法，常见：`立方米`、`m³`、`m3`、`立方公尺`、`千立方米`、`万立方米`、`亿立方米`、
`升`、`L`、`百万升`、`ML`、`吨`（水通常按 1 吨≈1 立方米计，但**不得自行换算**）、
`千吨`、`万吨`。

## 3. 质量单位（污染物）

常见：`吨`、`t`、`千吨`、`万吨`、`千克`、`kg`、`公斤`、`克`、`g`。

注意“吨”既可能是水量也可能是污染物质量，必须结合 `value_kind` 与表头判断：
`工业废水总量` 的“吨”是水量，`COD 排放量` 的“吨”是质量。数值本身不做单位语义转换。

## 4. 比例与强度单位

- 比例：`%`、`百分比`、`百分率`；原文写 `0.85` 且表头为 `%` 时，`raw_value="0.85"`、
  `unit="%"`，不得自行乘 100 改写数值。
- 强度：`吨/吨`、`m³/吨`、`立方米/吨`、`吨/千升`、`立方米/千升产量`、`吨/万元`、
  `m³/万元`、`吨水/吨产品` 等，整段照抄；分母口径写进 `classification_reason`。

## 5. 金额单位与币种

常见：`元`、`千元`、`万元`、`百万元`、`亿元`、`人民币`、`CNY`、`RMB`、`港元`、`HKD`、
`美元`、`USD`。

- 金额单位与币种都只能来自原文，**不得默认人民币**；
- 原文合写为 `人民币百万元` 时，`unit` 可逐字填 `人民币百万元`；分开标注时 `unit` 填单位
  （如 `亿元`），币种以原文句子作为证据（`raw_text`/`context_text` 保留含币种的完整表述）；
- 财务附注中的“千元”不是“千元人民币”，除非原文另有币种说明。

## 6. 常见近似符号与缩写

`Mt`=百万吨、`kt`=千吨、`ML`=百万升、`m³`=立方米、`kL`=千升、`GJ`、`kWh` 等按原文登记。
`万吨`、`万立方米`、`亿立方米` 等中文数量级单位一律保持原文，不换算成 `t`、`m³`。

## 7. 阈值与禁止

- 只登记，不换算；不把 `万吨` 改写成 `t`，不把 `亿元` 改写成 `元`；
- 不做跨单位比较、不四舍五入、不补零；
- 单位与数值来自不同页/不同表时，不得跨表拼成一个候选（除表头与数值同一张表跨页，
  且已在证据中分别记录页码并说明）；
- 报告给出多单位并列（如“1,366.20 万吨（13,662,000 立方米）”）时，取与表格表头一致的
  原文主单位，另一写法可写入 `alternatives`，不另建重复候选。
