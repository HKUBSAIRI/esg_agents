# 总磷排放量（Total phosphorus emission）

## 定义

报告期内企业向外排放的废水中**总磷（TP，总磷）**的质量总量，单位 t。总磷是水体富营养化
指标，常以“总磷（以 P 计）”表述，本指标只登记排放总质量，不换算为单质磷。

## 识别规则

同时满足条件才归 `total_phosphorus_emission`：

1. 名称明确为总磷：`总磷`、`总磷排放量`、`TP`、`总磷（TP）`、`总磷(TP)`、`总磷（以 P 计）`；
2. 单位为质量：`吨`、`t`、`千吨`、`万吨`、`千克`、`kg`、`公斤`；
3. 年份列与边界明确；是**排放量**。

典型写法：“总磷 6.5 吨”“总磷（以 P 计）排放量 800 千克”。

## 排除规则

- **COD/氨氮/总氮/BOD** → 各自指标，不得互相替代。
- **浓度**：`总磷浓度`、`mg/L`、`毫克/升` → 不是排放量。
- **去除量/削减量/产生量/处理量** ≠ 排放量。
- **磷酸盐/溶解性磷酸盐**单独披露 → 不是总磷，UNKNOWN（除非报告明确合称为总磷）。
- **合计未拆分**：“废水污染物排放量合计”不得摊派给总磷。
- **目标/同比变化**（“总磷排放量同比下降 3.0%”）不是排放量数值。
- **单位产品总磷排放量**（吨/千升）：强度，不属于本指标 → UNKNOWN。

## 标准单位与常见单位

- 标准单位：`t`（吨）。
- 常见原文单位：`吨`、`t`、`千吨`、`万吨`、`千克`、`kg`、`公斤`。
- 浓度单位不属本指标；只登记原文单位，不换算。

## 统计边界

- 集团/子公司/工厂边界写入 `reporting_boundary`；单厂数值不得当集团值。
- `data_year` 取列头年份（报告年度优先）。
- 排放去向（直排/纳管）口径有脚注时引用；无说明时 `ambiguity_flags` 加 `BOUNDARY_UNCLEAR`。
- 同一报告多表重复披露时保留最正式来源，其余写入 `alternatives`。

## 反例

| 原文 | 正确结论 | 原因 |
|---|---|---|
| “总磷 6.5 吨” | `total_phosphorus_emission` | 排放质量 |
| “总氮 203 吨” | `total_nitrogen_emission` | 不同指标 |
| “总磷浓度 0.5 mg/L” | UNKNOWN | 浓度 |
| “总磷去除量 20 吨” | UNKNOWN | 去除量不是排放量 |
| “COD 621 吨” | `cod_emission` | 不同污染物 |
| “总磷排放量同比下降 3.0%” | 无数值候选 | 变化率 |

## 证据要求

- 定量候选 `raw_value` 必填（保留千分位与原文写法），`unit` 必填。
- 证据含表题、行头（“总磷”）、列头（年份）、单位头（“吨”）、物理页码、逐字原文。
- `classification_reason` 引用行头与单位，说明是总磷而非其他污染物，且为排放质量不是浓度。
- 合计未拆分、浓度、去除量、目标值不得 CLASSIFIED。
