# 循环利用水量（Recycled water volume）

## 定义

报告期内企业内部**重复利用、循环利用或回用**的水量体积，单位 m³。包括重复用水量、循环
用水量、中水回用量、再生水回用量、冷凝水回收量等在企业边界内部再次利用的水。它**不是**
从外部新取的水，也**不是**向外排放的水。

## 识别规则

同时满足条件才归 `water_recycled_volume`：

1. 名称是体积型回用概念：`重复用水量`、`循环利用水量`、`重复利用水量`、`回用水量`、
   `中水回用量`、`再生水回用量`、`循环水量`、`废水回用量`、`冷凝水回用量`；
2. 单位为体积（立方米、m³、万立方米、千立方米、吨/万吨水）；
3. 年份列与边界明确。

典型写法：“重复用水量 181.99 万吨”“中水回用量 120,000 立方米”“循环利用水量 50 万立方米”。

## 排除规则

- **比率型名称**：`水循环利用率`、`重复利用率`、`中水回用率`、`回用率` → `water_recycling_rate`
  （%）；即使带“回用”字样，单位是 `%` 就是比率。
- **取水量/新鲜水用水量** → `water_withdrawal`；回用量不是取水量。
- **耗水量** → `water_consumption`；**排水量** → `water_discharge`；回用水未外排。
- **单位产品耗水量/水耗强度** → `water_intensity`。
- **循环冷却水循环量/循环水量（仅冷却系统内部循环）**：若报告未说明其与“重复利用水量”同
  口径，属口径不明 → NEEDS_REVIEW / UNKNOWN，不得直接当回用体积（冷却水循环量可能远大于
  统计口径的重复利用水量）。
- 节水项目“年节约用水 10,000 吨”“回收用水超过 15,000 吨”：是**项目/单厂**成效，不是集团
  回用总量；除非报告明确作为集团指标披露，否则 `reporting_boundary.level=SITE` 且不得与
  集团候选混同。
- 目标/计划回用量、同比变化率 → 不是实际数值。
- 只写“废水回收率” → 比率，不是体积。

## 标准单位与常见单位

- 标准单位：`m³`。
- 常见原文单位：`立方米`、`m³`、`m3`、`万立方米`、`千立方米`、`吨`、`万吨`。
- 只登记原文单位，不换算；换算由 Python normalizer 负责。

## 统计边界

- 集团 vs 单厂/项目：`reporting_boundary.level` 取 GROUP / SUBSIDIARY / SITE / UNKNOWN；
  工厂节水项目数据必须标 SITE，不得当作集团总量。
- `data_year` 取列头年份（报告年度优先）；统计期间按原文。
- 回用口径（是否含中水、冷凝水、冷却水）报告有说明时写入归类理由，无说明时
  `ambiguity_flags` 加 `DEFINITION_UNCLEAR`。

## 反例

| 原文 | 正确结论 | 原因 |
|---|---|---|
| “重复利用率 85%” | `water_recycling_rate` | 比率 |
| “重复用水量 181.99 万吨” | `water_recycled_volume` | 体积 |
| “单位产品耗水量 2.88 立方米/千升产量” | `water_intensity` | 强度 |
| “某工厂年回收用水超过 15,000 吨” | `water_recycled_volume`（SITE） | 单厂项目成效，边界不是集团 |
| “循环冷却水循环量 500 万立方米”（无口径说明） | NEEDS_REVIEW | 冷却循环口径可能不等于重复利用水量 |
| “2026 年重复用水量目标 X 万吨” | 不是实际值 | 目标 |

## 证据要求

- 定量候选 `raw_value` 必填（保留千分位与原文写法），`unit` 必填。
- 证据含表题、行头、列头、单位头、物理页码、逐字原文；口径脚注另附证据。
- `classification_reason` 引用“重复用水量/中水回用量”行头与体积单位，说明与
  `water_recycling_rate`（%）及 `water_withdrawal`（外部取水）的区别。
- 口径不明、边界不明的体积不得 CLASSIFIED。
