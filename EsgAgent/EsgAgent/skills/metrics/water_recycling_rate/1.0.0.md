# 水循环利用率（Water recycling rate）

## 定义

报告期内企业**重复利用/循环利用的水量**占总用水量的比例，以百分比表示。常见分子分母口径：
`重复利用率 = 重复利用水量 / (取水量 + 重复利用水量)`、`水循环利用率 = 循环水量 / 总用水量`；
具体口径以报告原文/脚注为准，写进 `classification_reason`。本指标是**比率（%）**，不是体积。

## 识别规则

同时满足条件才归 `water_recycling_rate`：

1. 名称是“率/比例”概念：`水循环利用率`、`重复利用率`、`水重复利用率`、`中水回用率`、
   `废水回用率`、`回用率`、`循环水利用率`、`water recycling rate`、`reuse rate`；
2. `unit` 为 `%`（或原文写“百分比”“百分率”）；
3. 报告给出实际值（不是目标值/承诺值），年份列或上下文年份明确。

典型写法：“水重复利用率 85%”“中水回用率 60.5%”“重复利用率达 92.3%”。

## 排除规则

- **体积型名称**：`重复用水量`、`循环利用水量`、`中水回用量`、`回用水量`、`重复利用水量`
  → `water_recycled_volume`；即使数值带“重复/回用”字样，只要单位是立方米/吨就是体积。
- **总量**：`总用水量`、`取水量`、`耗水量`、`排水量` → 各自指标。
- **目标值/承诺值**：“到 2026 年水重复利用率达到 95%”是目标，不是实际披露值 →
  不生成定量候选（可作为 `water_policy` 定性证据，或 UNKNOWN 并在 `alternatives` 说明）。
- **同比变化/提升幅度**：“重复利用率较上年提高 3 个百分点”“较上年下降 2%”不是当前利用率。
- **占比类无关指标**：水压力地区取水占比、再生水占供水比例等，若不属于“重复利用水量/总
  用水量”口径 → UNKNOWN，不得硬归本指标。
- “循环冷却水循环倍率”“浓缩倍数”不是回用率 → UNKNOWN。

## 标准单位与常见单位

- 标准单位：`%`。
- 常见原文单位：`%`、`百分比`、`百分率`；原文以小数给出但表头为 `%` 时，`raw_value` 保留
  原文小数（如 `0.85`），`unit="%"`，**不得自行乘 100 改写**。
- 若原文是“百分点”（如“提高 3 个百分点”），属于变化量而非比率值，按变化量处理，不建候选。

## 统计边界

- 集团/子公司/工厂边界写入 `reporting_boundary`；单厂“重复用水率”不得当集团值。
- `data_year` 取列头年份（报告年度优先）；目标年份不是 `data_year`，目标值不是实际值。
- 分子分母口径（是否含中水回用、是否含冷却水循环）报告有脚注时必须引用；无说明时
  `ambiguity_flags` 加 `DEFINITION_UNCLEAR`，可 NEEDS_REVIEW。
- 同一报告同时披露“重复用水量（体积）”和“重复利用率（%）”时，分别建两条候选，
  不得互相推导（不得用体积÷水量自行算出比率）。

## 反例

| 原文 | 正确结论 | 原因 |
|---|---|---|
| “重复用水量 181.99 万吨” | `water_recycled_volume` | 体积 |
| “水重复利用率 85%” | `water_recycling_rate` | 比率 |
| “2026 年水重复利用率目标 95%” | 不是实际值 | 目标 |
| “重复利用率较上年提高 2.5 个百分点” | 不是当前值 | 变化量 |
| “重复利用率 = 重复用水量/总用水量” | 算法说明，本身不是数值 | 口径说明 |
| “中水回用量 12 万立方米” | `water_recycled_volume` | 体积 |

## 证据要求

- 定量候选 `raw_value` 必填（保留原文写法，含 `%` 时 `raw_value` 仍只放数字部分），
  `unit` 必填。
- 证据含表题、行头、列头/年份、单位头、物理页码、逐字原文；口径脚注另附证据。
- `classification_reason` 必须引用“率/利用率”行头、`%` 单位，并说明与体积型
  `water_recycled_volume` 的区别；若报告同时给出体积，写入 `alternatives`。
- 目标值、变化量、口径不明的比率不得 CLASSIFIED。
