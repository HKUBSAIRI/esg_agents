# 总氮排放量（Total nitrogen emission）

## 定义

报告期内企业向外排放的废水中**总氮（TN，总氮）**的质量总量，单位 t。总氮包含氨氮、硝酸盐
氮、亚硝酸盐氮等，是独立于氨氮的指标。

## 识别规则

同时满足条件才归 `total_nitrogen_emission`：

1. 名称明确为总氮：`总氮`、`总氮排放量`、`TN`、`总氮（TN）`、`总氮(TN)`；
2. 单位为质量：`吨`、`t`、`千吨`、`万吨`、`千克`、`kg`、`公斤`；
3. 年份列与边界明确；是**排放量**。

典型写法：“总氮 203 吨”“总氮排放量 1,200 千克”。

## 排除规则

- **氨氮**（NH3-N）→ `ammonia_nitrogen_emission`；不得混用，不得用氨氮数值充当总氮。
- **硝酸盐氮/亚硝酸盐氮**单独披露 → 不是总氮，UNKNOWN（除非报告明确“总氮=各项之和”且
  给出合计，此时取合计）。
- **浓度**：`总氮浓度`、`mg/L` → 不是排放量。
- **去除量/削减量/产生量/处理量** ≠ 排放量。
- **COD/总磷/BOD** → 各自指标。
- **合计未拆分**：“废水污染物排放量合计”不得摊派给总氮。
- **目标/同比变化**（“总氮排放量同比下降 7.7%”）不是排放量数值。
- **单位产品总氮排放量**（吨/千升）：强度，不属于本指标 → UNKNOWN。
- 废水以外的总氮（如废气）→ 不是本指标。

## 标准单位与常见单位

- 标准单位：`t`（吨）。
- 常见原文单位：`吨`、`t`、`千吨`、`万吨`、`千克`、`kg`、`公斤`。
- 浓度单位不属本指标；只登记原文单位，不换算。

## 统计边界

- 集团/子公司/工厂边界写入 `reporting_boundary`；单厂数值不得当集团值。
- `data_year` 取列头年份（报告年度优先）。
- 排放去向（直排/纳管）口径有脚注时引用；无说明时 `ambiguity_flags` 加 `BOUNDARY_UNCLEAR`。
- 同一报告同时给出总氮与氨氮时，两条候选各自独立，`alternatives` 互相注明区别。

## 反例

| 原文 | 正确结论 | 原因 |
|---|---|---|
| “总氮 203 吨” | `total_nitrogen_emission` | 排放质量 |
| “氨氮 58 吨” | `ammonia_nitrogen_emission` | 不同指标 |
| “总氮排放浓度 15 mg/L” | UNKNOWN | 浓度 |
| “总氮去除量 500 吨” | UNKNOWN | 去除量不是排放量 |
| “总磷 6.5 吨” | `total_phosphorus_emission` | 不同污染物 |
| “总氮排放量同比下降 7.7%” | 无数值候选 | 变化率 |

## 证据要求

- 定量候选 `raw_value` 必填（保留千分位与原文写法），`unit` 必填。
- 证据含表题、行头（“总氮”）、列头（年份）、单位头（“吨”）、物理页码、逐字原文。
- `classification_reason` 引用行头与单位，说明是总氮而非氨氮/COD，且为排放质量不是浓度。
- 合计未拆分、浓度、去除量、目标值不得 CLASSIFIED。
