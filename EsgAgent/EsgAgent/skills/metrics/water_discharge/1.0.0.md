# 总排水量（Total water discharge）

## 定义

报告期内企业向**外部**排放的废水量，包括排入市政管网（纳管）、排入地表/地下水体（直排）
及交由第三方处理的部分，单位 m³。排水的特征是离开企业统计边界、进入外部受纳方。

## 识别规则

同时满足条件才归 `water_discharge`：

1. 行头/正文明确是向外排放的水量：`总排水量`、`排水量`、`废水排放量`、`污水排放量`、
   `工业废水总量`、`废水排放总量`、`外排废水量`、`排入市政管网的废水量`；
2. 单位为体积（立方米、m³、万立方米、千立方米、吨/万吨）；
3. 年份列与边界明确（集团/子公司/厂区）。

典型写法：“废水排放量 234.67 万吨”“工业废水总量 14,352,540 立方米”“总排水量 50,000 m³”。

## 排除规则

- **取水量/新鲜水用水量** → `water_withdrawal`；**耗水量** → `water_consumption`。
- **污染物排放量**（COD、氨氮、总氮、总磷，单位吨）→ 对应污染物指标，不是水量。
  同一报告同时披露废水水量与 COD 时，分别建候选，不得混为一条。
- **废水处理量/废水治理量/污水处理能力**：企业内部处理规模，不等于向外排放量；
  只有明确“处理后外排”才可视为排水。
- **中水回用量/重复用水量/循环利用水量** → `water_recycled_volume`（未向外排放）。
- **废水回用率/水循环利用率**（%）→ `water_recycling_rate`。
- **排放浓度**（mg/L、毫克/吨）→ 不是排放量，本指标不接收；UNKNOWN。
- **目标/承诺/计划减排量**、同比变化率、排放限额 → 不是实际排水量。
- 只给“废水污染物排放量”合计（吨）而未拆分：属于污染物而非水量，水量部分 UNKNOWN，
  不得用“合计吨数”冒充排水量。

## 标准单位与常见单位

- 标准单位：`m³`（立方米）。
- 常见原文单位：`立方米`、`m³`、`m3`、`万立方米`、`千立方米`、`吨`、`万吨`、`千吨`。
- 浓度类单位（`mg/L`、`毫克/升`、`毫克/吨`）不属于本指标；带分母的是浓度或强度。
- 只登记原文单位，不换算。

## 统计边界

- 排水边界很关键：纳管、直排、回用、第三方处理是否计入，报告有说明时必须写入
  `classification_reason`；未说明时 `ambiguity_flags` 加 `BOUNDARY_UNCLEAR`。
- 集团 vs 单厂/站点：`reporting_boundary.level` 取 GROUP / SUBSIDIARY / SITE / UNKNOWN，
  单厂数值不得与集团数值混为同一候选。
- `data_year` 取列头年份（报告年度优先）；`statistical_period` 按原文。
- 报告分段披露“直排量”“纳管量”时，分别建候选，不自行加总；除非报告本身给出合计行，
  此时取合计行并保留分项为 `alternatives`。

## 反例

| 原文 | 正确结论 | 原因 |
|---|---|---|
| “总取水量 1,000 万立方米” | `water_withdrawal` | 取水 |
| “工业废水总量 14,352,540 立方米” | `water_discharge` | 排水水量 |
| “COD 排放量 621 吨” | `cod_emission` | 污染物质量 |
| “废水污染物排放量 24.64 吨” | UNKNOWN | 污染物合计，未拆分且非水量 |
| “废水排放浓度 9,060.09 毫克/吨” | UNKNOWN | 浓度不是排放量 |
| “重复用水量 181.99 万吨” | `water_recycled_volume` | 内部回用 |
| “2025 年废水排放量同比减少 7.6%” | 无数值候选 | 变化率 |
| “计划 2026 年废水排放量降至 X 万吨” | 不是实际值 | 目标 |

## 证据要求

- 定量候选 `raw_value` 必填（保留千分位与原文写法），`unit` 必填。
- 证据含表题、行头、列头、单位头、物理页码、逐字原文；排水口径/去向若有脚注，另附证据。
- `classification_reason` 引用行头与单位，并说明“向外排放”的口径（纳管/直排/第三方），
  以及为何不是取水或污染物。相关候选写入 `alternatives`。
- 边界或去向不明、无法确认是排水还是处理量时，不得 CLASSIFIED。
