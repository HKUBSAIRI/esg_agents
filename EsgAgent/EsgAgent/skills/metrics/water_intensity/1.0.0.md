# 水资源消耗强度（Water intensity）

## 定义

单位产出（单位产品、千升产量、吨产品、万元营收等）对应的水资源取用量或消耗量，是**强度**
指标而非总量。常见形式：`吨水/吨产品`、`立方米/千升产量`、`m³/吨`、`立方米/吨`、
`吨/万元`、`水资源消耗强度`。标准单位在指标登记中留空（null），保留原文单位，由 Python 与
分母口径共同决定是否可比较。

## 识别规则

同时满足条件才归 `water_intensity`：

1. 名称/单位含**分母**：`单位产品耗水量`、`单位产品取水量`、`单位产品用水量`、
   `水资源消耗强度`、`水耗强度`、`吨水/吨产品`、`m³/t`、`立方米/千升产量`、`吨/万元`；
2. 单位是“体积/产出”形式的复合单位；
3. 分母口径（产品产量、千升产量、吨产品、万元营收等）能从表头/脚注读到。

典型写法：“啤酒生产单位产品耗水量 2.88 立方米/千升产量”“水资源消耗强度 1.87 吨/吨”
“2025 年饮用水水单耗 1.77 吨/吨”。

## 排除规则

- **总量型**：`总取水量`、`总耗水量`、`总用水量`、`总排水量` → 各自体积指标。
- **比率型**：`水循环利用率`、`重复利用率` → `water_recycling_rate`（%）。
- **浓度/密度**：`mg/L`、`毫克/吨`、`COD 浓度` 不是强度，也不是本指标。
- **单位产出营收的用水强度**（`吨/万元`）：若分母是营收而非产量，仍属强度，但必须在
  `classification_reason` 写明分母；是否可与其他口径比较由 Python 侧判断。
- “单位产品耗水下降 1.5%”“较上年下降”是变化率，不是强度值。
- “目标：2026 年单位产品耗水量 2.5 立方米/千升”是目标，不是实际值。
- 只写“水单耗 1.77”而单位/分母缺失 → NEEDS_REVIEW（`UNIT_MISSING`），不得猜测分母。

## 标准单位与常见单位

- 指标登记 `canonical_unit=null`：强度口径因分母而异，**不做统一换算**，`unit` 原样登记。
- 常见原文单位：`吨/吨`、`吨水/吨产品`、`立方米/吨`、`m³/吨`、`立方米/千升产量`、
  `m³/kL`、`吨/万元`、`立方米/万元`。
- 分母写法（如“千升产量”“合格产品产量”“营业收入”）必须来自原文表头/脚注，写进
  `classification_reason`，不得自行补全。

## 统计边界

- 集团/子公司/工厂边界写入 `reporting_boundary`；单厂水单耗不得当集团值。
- `data_year` 取列头年份；强度通常按年度计算，跨年不可比，`statistical_period` 按原文。
- 分母是“产品产量”还是“营业收入”会显著影响可比性；报告有脚注时引用脚注原文。
- 同一报告用不同分母披露多个强度（吨/吨 与 吨/万元）时，分别建候选，不合并。

## 反例

| 原文 | 正确结论 | 原因 |
|---|---|---|
| “单位产品耗水量 2.88 立方米/千升产量” | `water_intensity` | 强度 |
| “水资源消耗强度 1.87 吨/吨” | `water_intensity` | 强度 |
| “耗水量 500 万立方米” | `water_consumption` | 总量 |
| “水循环利用率 85%” | `water_recycling_rate` | 比率 |
| “单位产品耗水量较上年下降 1.5%” | 无数值候选 | 变化率 |
| “单位产品耗水量目标 2.5 立方米/千升” | 不是实际值 | 目标 |
| “2025 年饮用水水单耗 1.77 吨/吨”（脚注给出分母） | `water_intensity` | 强度且分母明确 |

## 证据要求

- 定量候选 `raw_value` 必填（保留原文写法），`unit` 必填（复合单位整段照抄）。
- 证据含表题、行头、列头/年份、单位头、物理页码、逐字原文；分母口径脚注另附证据。
- `classification_reason` 必须引用强度名称、复合单位与分母口径，并说明为何不是总量/比率。
- 分母或单位缺失、无法确认强度口径时，不得 CLASSIFIED。
