# 总取水量（Total water withdrawal）

## 定义

报告期内企业从**外部水源**取得并进入企业统计边界的水量总和，单位 m³。外部水源包括市政
自来水/市政供水、地表水（河流、湖泊、水库）、地下水（含矿泉水井）、第三方供水、其他组织
供水，以及按报告口径计入的雨水收集量。对应 GRI 303-3 / SASB 的 water withdrawal 口径。

## 识别规则

同时满足以下条件才归 `water_withdrawal`：

1. 表格行头/正文明确是**从外部取得**的水：`总取水量`、`取水量`、`新鲜水用水量`、
   `新鲜水取用量`、`新水取用量`、`取用新鲜水量`、`市政供水量`、`自来水用量`、
   `地表水取用量`、`地下水取用量`、`总供水量（外部）`；
2. 单位是体积（立方米、m³、万立方米、千立方米、吨/万吨水）；
3. 年份列明确（取报告年度列），边界明确（集团/子公司/厂区）。

可 CLASSIFIED 的典型写法：

- “总取水量 100,000 立方米”“年度新鲜水用水量 1,366.20 万吨”
- “从市政管网取水 X 万立方米；自备水源取水 Y 万立方米”（分别建候选，不自行加总）

## 排除规则

- **耗水量**（未回到可用水体的部分）→ `water_consumption`；取水 ≠ 耗水。
- **排水量/废水排放量**（向外排放）→ `water_discharge`；取水 ≠ 排水。
- **重复用水量/循环利用水量/中水回用量**（内部再次利用）→ `water_recycled_volume`。
- **水循环利用率/重复利用率**（%）→ `water_recycling_rate`。
- **单位产品取水量/耗水量、吨水/吨产品**（强度）→ `water_intensity`。
- **只写“用水量”“总用水量”“water use”且无“外部取水/新鲜水/取水”口径**：按当前研究策略，在报告未另披露耗水量时可推定为取水；必须加`DEFINITION_INFERRED`，保留原始名称、推定理由及备选解释。此类值不是报告明示口径，正式发布仍需审核。上下文不足以支持该策略时为UNKNOWN，不得推定耗水或排水。
- **取水许可量/许可额度/批准取水量**：是许可上限，不是实际取水量 → UNKNOWN。
- **目标值/承诺值/计划值**（“到 2026 年取水量下降 x%”）→ 不是实际数值。
- **同比变化/占比/百分比**（“取水量较上年下降 2.0%”）→ 不是水量数值。
- 设计取水能力、水厂产能、供水量目标 → 不是实际取水量。

## 标准单位与常见单位

- 标准单位：`m³`（立方米）。
- 常见原文单位：`立方米`、`m³`、`m3`、`万立方米`、`千立方米`、`亿立方米`、`吨`、`万吨`、
  `千吨`（水按体积口径时常见）。**只登记原文单位，不换算**；换算由 Python normalizer 负责。

## 统计边界

- 默认取**集团合并口径**；子公司/工厂/站点数据须在 `reporting_boundary` 写明
  `level=SUBSIDIARY|SITE` 与描述，不得与集团口径混为同一候选。
- `data_year` 取列头/表头年份（优先报告年度）；`statistical_period` 尽量写
  `YYYY-01-01/YYYY-12-31`，原文给出其他期间则照抄（如财年）。
- 取水来源（市政/地表/地下水）不同不改变指标，但可在 `classification_reason` 说明。
- 是否包含雨水收集、冷凝水回收等，按报告口径；报告未说明时在 `ambiguity_flags` 标注
  `BOUNDARY_UNCLEAR`，不要自行加减。

## 反例

| 原文 | 正确结论 | 原因 |
|---|---|---|
| “总用水量 1,200 万立方米”（报告未另披露耗水量） | `water_withdrawal`（`DEFINITION_INFERRED`） | 按总取水量推定，reason 写明推定口径 |
| “总用水量 1,200 万立方米 + 总耗水量 800 万立方米” | 分别归 `water_withdrawal` / `water_consumption` | 报告区分了取水与耗水 |
| “总耗水量 850 万立方米” | `water_consumption` | 行头明确是耗水 |
| “重复用水量 300 万立方米” | `water_recycled_volume` | 内部重复利用体积 |
| “单位产品取水量 2.5 立方米/吨” | `water_intensity` | 强度，不是总量 |
| “2025 年取水量较 2024 年下降 3.2%” | 无数值候选 | 变化率不是水量 |
| “取水许可量 500 万立方米/年” | UNKNOWN | 许可额度不是实际取水 |
| “计划 2026 年取水量降至 X 万吨” | 不是实际值 | 目标值 |
| “新鲜水用水量 1,366.20 万吨”（脚注定义为新鲜水取用） | `water_withdrawal` | 口径明确为外部取水 |

## 证据要求

- 定量候选 `raw_value` 必填（保留千分位与原文写法），`unit` 必填，`raw_text` 可空。
- 证据须含：表题、行头（如“总取水量”）、列头（年份）、单位头、原 PDF **物理页码**、
  逐字原文；叙述型披露摘包含数值与口径的完整原句。
- 归类理由必须引用行头/表题/原文及口径（如“行头为总取水量，单位为立方米，2025 年集团口径”）。
- 口径不明、来源不明、单位不明时不得 CLASSIFIED；按 UNKNOWN / NEEDS_REVIEW /
  INSUFFICIENT_EVIDENCE 处理。
