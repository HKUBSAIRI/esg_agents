# 营业收入（Revenue）

## 定义

报告期内企业**营业收入/营业额**的金额，来源可以是 ESG/可持续发展报告的“经济责任/可持续
发展指标/财务摘要”页，也可以是年报财务数据表。本指标只提取报告明确给出的金额；`raw_value`
保留原文数字写法，`unit` 保留原文金额单位；币种按原文判断（见下），币种不明不阻断指标归类。

## 识别规则

同时满足条件才归 `revenue`：

1. 名称明确：`营业收入`、`营业额`、`收入总额`、`营业总收入`、`Revenue`、`Turnover`；
2. 报告给出具体金额（数字 + 金额单位）；
3. 年份/期间明确（取报告年度）；是**实际值**不是目标值。

典型写法：“2025 年营业收入 324.73 亿元”“2025 年营业额为人民币 12,345 百万元”。

## 排除规则

- **净利润、归母净利润、利润总额、毛利、EBIT/EBITDA、总资产、净资产、纳税总额** →
  不是营业收入。
- **营业收入增长率/同比变化/占比**（“营业收入同比增长 5%”“营收占比 30%”）→ 不是金额数值。
- **目标值/预测值**（“预计 2026 年营收达到 X 亿元”）→ 不是实际值。
- **分部收入/分产品收入**：若报告明确是“某业务分部营业收入”，属 `level=SUBSIDIARY`
  或分部口径，可建候选并在 `classification_reason` 写明；若只给“某产品营收占比”则无数值。
- **金额单位缺失**：只有“营业收入 324.73”而没有单位 → NEEDS_REVIEW（`UNIT_MISSING`），
  不得猜“亿元”。
- **币种判断**（不阻断指标归类，只影响币种字段）：
  - 原文含 `港元`、`港币`、`HKD`、`HK$` → HKD；含 `美元`、`USD`、`US$` → USD；
  - 原文含 `人民币`、`RMB`、`CNY`，或金额单位只用 `元`/`万元`/`百万元`/`亿元`
    （中文内地报告惯例）→ CNY；
  - 既无币种词也无上述人民币金额单位 → 仍可 `classification_status=CLASSIFIED`、
    `metric_id=revenue`，但 `ambiguity_flags` 必须加 `CURRENCY_UNCLEAR`，币种留待人工确认；
  - 绝不把港元/美元金额当人民币；不同币种分别建候选，不得相加或混为同一候选。
- 营收强度/人均营收/单位营收排放等 → 不是营业收入。
- ESG 报告中“经济责任”表若只给“资产总额/利润总额/纳税总额”，不得把其中任何一项当营收。

## 标准单位与常见单位

- 指标登记标准单位：`CNY_million`（百万元人民币）。
- 常见原文单位：`元`、`千元`、`万元`、`百万元`、`亿元`、`人民币`、`CNY`、`RMB`、`港元`、
  `HKD`、`美元`、`USD`。
- **只登记原文单位，不换算、不四舍五入**；`raw_value="324.73"`、`unit="亿元"`。
- 原文合写“人民币百万元”时 `unit` 可逐字保留为“人民币百万元”；单位与币种分开标注时，
  `unit` 填单位文本，币种通过证据原文（`raw_text`/`context_text`）体现。
- 千分位保留在 `raw_value` 中（如 `"12,345"`），不得先清洗成 `12345`。

## 统计边界

- 集团合并口径 vs 分部/子公司：`reporting_boundary.level` 取 GROUP / SUBSIDIARY / SITE /
  UNKNOWN，并在描述中写明“合并/分部”。
- `data_year` 取金额对应年份（报告年度优先）；`statistical_period` 写财年期间
  （如 `2025-01-01/2025-12-31`），报告另有财年定义时照抄。
- 币种不同的金额（港元/美元）不得与人民币口径混为同一候选；分别保留。
- 同一报告“亮点页”与“财务摘要/附录”重复披露：保留最正式、最完整的来源（财务表 >
  亮点页），其余写入 `alternatives`；数值不一致分别保留并标 CONFLICT。

## 反例

| 原文 | 正确结论 | 原因 |
|---|---|---|
| “2025 年营业收入 324.73 亿元” | `revenue`（unit=亿元） | 明确金额 |
| “2025 年归属于母公司股东的净利润 45.88 亿元” | 不是 revenue | 净利润 |
| “营业收入同比下降 2.0%” | 无数值候选 | 变化率 |
| “预计 2026 年营业收入 350 亿元” | 不是实际值 | 预测 |
| “营业收入 324.73”（无单位） | NEEDS_REVIEW | 单位缺失 |
| “2025 年营业额 1,234 百万港元” | `revenue`（unit=百万港元，HKD） | 币种来自原文 |
| “2025 年营业收入 324.73 亿元” | `revenue`（unit=亿元，CNY） | “元/亿元”按人民币惯例判断 |
| “研发投入占主营业务收入 0.70%” | 不是 revenue | 占比 |
| “在港业务营收同比增长 49%” | 无数值候选 | 变化率 |

## 证据要求

- 定量候选 `raw_value` 必填（保留原文写法与千分位），`unit` 必填，币种依据须在证据原文中
  可见；`raw_text` 建议保留含币种的完整原句。
- 证据含表题/页面标题、行头（“营业收入”）、列头（年份/期间）、单位头、物理页码、逐字原文；
  亮点页数字块没有表格时，`source_type=TEXT`，`context_text` 记录所在板块（如“经济责任”）。
- `classification_reason` 引用名称、金额单位与币种来源，并说明为何不是利润/增长率/占比。
- 金额单位不明（只有数字）不得 CLASSIFIED；币种不明可以 CLASSIFIED 但必须加
  `CURRENCY_UNCLEAR`；只有占比/增长率、目标或预测值不得 CLASSIFIED。
