# COD 排放量（COD emission）

## 定义

报告期内企业向外排放的废水中**化学需氧量（COD / CODcr，化学需氧量）**的质量总量，单位 t。
COD 是水质污染指标，属于质量维度，不是水量。

## 识别规则

同时满足条件才归 `cod_emission`：

1. 名称明确为 COD：`COD`、`CODcr`、`化学需氧量`、`化学需氧量(COD)`、`COD 排放量`、
   `化学需氧量排放量`；
2. 单位为质量：`吨`、`t`、`千吨`、`万吨`、`千克`、`kg`、`公斤`；
3. 年份列与边界明确；且是**排放量**（不是产生量/去除量/削减量/浓度）。

典型写法：“COD 排放量 23.60 吨”“化学需氧量(COD) 621 吨”。

## 排除规则

- **浓度**：`COD 浓度`、`mg/L`、`毫克/升`、`毫克/吨` → 不是排放量；UNKNOWN 或按报告口径
  不建候选。
- **去除量/削减量/处理量**：`COD 去除量`、`削减量`、`处理量` ≠ 排放量。
- **产生量**：`COD 产生量` 不等于排放量。
- **其他污染物**：`BOD`、`氨氮`、`总氮`、`总磷` 分别对应各自指标，不得把 COD 数值套用到
  其他指标，也不得用其他污染物数值充当 COD。
- **合计未拆分**：报告只给“废水污染物排放量”合计（吨）而未列 COD → UNKNOWN，禁止摊派。
- **目标/承诺/同比变化**：`2026 年单位产品 COD 排放量较 2019 年下降 36%` 是目标/变化率，
  不是排放量数值；“COD 排放量同比下降 7.7%” 也不是排放量。
- **单位产品 COD 排放量**（吨/千升、吨/吨产品）：是强度，不属于本指标 → UNKNOWN（可
  `alternatives` 说明为强度）。
- 废气中的 COD 或非废水口径的 COD → 不是本指标。

## 标准单位与常见单位

- 标准单位：`t`（吨）。
- 常见原文单位：`吨`、`t`、`千吨`、`万吨`、`千克`、`kg`、`公斤`、`克`。
- 浓度单位（`mg/L`、`毫克/吨`）不属本指标；只登记原文单位，不换算。

## 统计边界

- 集团/子公司/工厂边界写入 `reporting_boundary`；单厂 COD 数值不得当集团值。
- `data_year` 取列头年份（报告年度优先）；`statistical_period` 按原文。
- 排放去向（直排/纳管）是否计入：报告有脚注时引用，无说明时 `ambiguity_flags` 加
  `BOUNDARY_UNCLEAR`，可 NEEDS_REVIEW。
- 同一报告多表重复披露 COD 时保留最正式来源（附录 KPI 表优先），其余写入 `alternatives`。

## 反例

| 原文 | 正确结论 | 原因 |
|---|---|---|
| “化学需氧量(COD) 621 吨” | `cod_emission` | 排放质量 |
| “COD 排放浓度 50 mg/L” | UNKNOWN | 浓度不是排放量 |
| “COD 去除量 1,200 吨” | UNKNOWN | 去除量不是排放量 |
| “废水污染物排放量 24.64 吨” | UNKNOWN | 合计未拆分，禁止摊派 |
| “氨氮排放量 58 吨” | `ammonia_nitrogen_emission` | 不同污染物 |
| “2026 年单位产品 COD 排放量较 2019 年下降 36%” | 不是实际值 | 目标/变化率 |
| “COD 排放量同比下降 7.7%” | 无数值候选 | 变化率 |

## 证据要求

- 定量候选 `raw_value` 必填（保留千分位与原文写法），`unit` 必填。
- 证据含表题、行头（如“化学需氧量(COD)”）、列头（年份）、单位头（“吨”）、物理页码、
  逐字原文；脚注（如排放去向、口径）另附证据。
- `classification_reason` 引用行头与单位，说明是质量而非水量/浓度，并说明为何不是其他
  污染物；相关候选写入 `alternatives`。
- 合计未拆分、浓度、去除量、目标值不得 CLASSIFIED。
