# 总耗水量（Total water consumption）

## 定义

报告期内企业取用的水**未返回同一或另一可用水体**的部分，即因蒸发、产品含水、转移到其他
流域或被生物/化学过程消耗而损失的水量，单位 m³。理论上 `耗水量 = 取水量 − 排水量`，
但该等式只在报告明确给出时成立；**提取阶段不得自行相减推算**。

## 识别规则

同时满足以下条件才归 `water_consumption`：

1. 行头/正文明确是“耗水”概念：`总耗水量`、`耗水量`、`水资源消耗量`、`水消耗量`、
   `consumption`，且**不是强度**；
2. 单位为体积（立方米、m³、万立方米、千立方米、吨/万吨水）；
3. 报告给出了耗水口径（如“蒸发及产品含水”“取水量减排水量”），或行头本身就是“总耗水量”、
   且上下文表明是公司实际耗水而非计划/目标。

典型写法：“总耗水量 850 万立方米”“2025 年耗水量 500,000 立方米”。

## 排除规则

- **取水量/新鲜水用水量**（从外部取得）→ `water_withdrawal`；取水 ≠ 耗水。
- **排水量/废水排放量**（向外排放）→ `water_discharge`。
- **重复用水量/循环利用水量**（内部回用）→ `water_recycled_volume`。
- **单位产品耗水量/吨水/吨产品/立方米/千升产量**（强度）→ `water_intensity`；注意“单位产品
  耗水量”虽然含“耗水”二字，但是强度，不能归本指标。
- 只写“用水量/总用水量/water use”且无耗水口径 → **不得归本指标**；若报告未另披露耗水量，
  该值归 `water_withdrawal`（总取水量，加 `DEFINITION_INFERRED`），见 water_withdrawal Skill。
  （HKEX A2.2 “总耗水量”在不同报告里口径不一，必须看表格行头与脚注。）
- 报告中只有取水量与排水量、未直接给出耗水量 → **不得相减推算**；标 UNKNOWN 或
  NEEDS_REVIEW，`alternatives` 说明“报告未直接披露耗水量，可由取水−排水在 Python 侧计算
  （需审核确认口径）”，不得写 `raw_value`。
- 目标/承诺/计划耗水量、同比变化率、占比、耗水强度 → 不是总量数值。

## 标准单位与常见单位

- 标准单位：`m³`（立方米）。
- 常见原文单位：`立方米`、`m³`、`m3`、`万立方米`、`千立方米`、`亿立方米`、`吨`、`万吨`；
  常见错误是把强度单位 `吨/吨`、`立方米/千升产量` 当作水量——带分母的是强度。
- 只登记原文单位，不换算；换算由 Python 负责。

## 统计边界

- 集团/子公司/厂区边界须在 `reporting_boundary` 写明，不得混用。
- `data_year` 取列头/表头年份（报告年度优先）；`statistical_period` 按原文。
- 口径是否包含冷却水蒸发、产品含水、回用水内部循环，报告有说明时写入归类理由；
  无说明时 `ambiguity_flags` 加 `BOUNDARY_UNCLEAR`。
- 报告同时披露“取水量”“排水量”“耗水量”时，各自独立建候选，不得互相覆盖或相加。

## 反例

| 原文 | 正确结论 | 原因 |
|---|---|---|
| “总取水量 1,000 万立方米” | `water_withdrawal` | 取水，不是耗水 |
| “总耗水量 300 万立方米” | `water_consumption` | 行头明确为耗水 |
| “单位产品耗水量 2.88 立方米/千升产量” | `water_intensity` | 强度 |
| “用水量 21,725 千立方米”且无耗水口径 | 不是本指标；归 `water_withdrawal` | 报告未区分取水/耗水，按总取水量推定 |
| “取水量 1,000 万立方米、排水量 300 万立方米”（未给耗水） | 不生成耗水候选 | 禁止自行相减 |
| “2025 年耗水量较上年下降 4%” | 无数值候选 | 变化率 |

## 证据要求

- 定量候选 `raw_value` 必填（保留千分位与原文写法），`unit` 必填。
- 证据含表题、行头、列头、单位头、物理页码、逐字原文；耗水口径若有脚注，单独作为
  evidence 引用。
- `classification_reason` 必须引用“耗水量”行头/定义原文，并说明与取水、排水的区别；
  若存在 `water_withdrawal`/`water_discharge` 候选，在 `alternatives` 注明。
- 口径不明、仅靠“耗水”二字而无法确认统计方式时，不得 CLASSIFIED。
