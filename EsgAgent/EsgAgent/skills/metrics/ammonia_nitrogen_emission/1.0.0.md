# 氨氮排放量（Ammonia nitrogen emission）

## 定义

报告期内企业向外排放的废水中**氨氮（NH3-N）**的质量总量，单位 t。氨氮是水体富营养化
关键污染物之一，与总氮是不同的指标。

## 识别规则

同时满足条件才归 `ammonia_nitrogen_emission`：

1. 名称明确为氨氮：`氨氮`、`氨氮排放量`、`NH3-N`、`氨氮（NH3-N）`、`氨氮(NH3-N)`；
2. 单位为质量：`吨`、`t`、`千吨`、`万吨`、`千克`、`kg`、`公斤`；
3. 年份列与边界明确；是**排放量**。

典型写法：“氨氮排放量 1.04 吨”“氨氮 58 吨”“NH3-N 排放量 300 千克”。

## 排除规则

- **总氮**（TN）→ `total_nitrogen_emission`；氨氮是总氮的组成之一，但报告分别披露时必须
  分别建候选，**不得把总氮数值当氨氮**，也不得用氨氮数值充总氮。
- **浓度**：`氨氮浓度`、`mg/L`、`毫克/升` → 不是排放量。
- **去除量/削减量/产生量/处理量** ≠ 排放量。
- **COD/BOD/总磷** → 各自指标。
- **合计未拆分**：“废水污染物排放量合计 x 吨”不得摊派给氨氮。
- **目标/同比变化**：“单位产品氨氮排放量较 2019 年下降 43%”“氨氮排放量同比下降 7.9%”
  不是排放量数值。
- **单位产品氨氮排放量**（吨/千升）：强度，不属于本指标 → UNKNOWN。
- 废气/固体废物中的氨氮 → 不是本指标。

## 标准单位与常见单位

- 标准单位：`t`（吨）。
- 常见原文单位：`吨`、`t`、`千吨`、`万吨`、`千克`、`kg`、`公斤`。
- 浓度单位不属本指标；只登记原文单位，不换算。

## 统计边界

- 集团/子公司/工厂边界写入 `reporting_boundary`；单厂数值不得当集团值。
- `data_year` 取列头年份（报告年度优先）。
- 排放去向（直排/纳管）口径有脚注时引用；无说明时 `ambiguity_flags` 加 `BOUNDARY_UNCLEAR`。
- 同一报告在多表重复披露时保留最正式来源，其余写入 `alternatives`。

## 反例

| 原文 | 正确结论 | 原因 |
|---|---|---|
| “氨氮 58 吨” | `ammonia_nitrogen_emission` | 排放质量 |
| “总氮 203 吨” | `total_nitrogen_emission` | 不同指标 |
| “氨氮排放浓度 8 mg/L” | UNKNOWN | 浓度 |
| “氨氮去除量 120 吨” | UNKNOWN | 去除量不是排放量 |
| “COD 621 吨” | `cod_emission` | 不同污染物 |
| “2026 年单位产品氨氮排放量较 2019 年下降 43%” | 不是实际值 | 目标/变化率 |
| “废水污染物排放量 24.64 吨” | UNKNOWN | 合计未拆分 |

## 证据要求

- 定量候选 `raw_value` 必填（保留千分位与原文写法），`unit` 必填。
- 证据含表题、行头（“氨氮”）、列头（年份）、单位头（“吨”）、物理页码、逐字原文。
- `classification_reason` 引用行头与单位，说明是氨氮而非总氮/COD，且为排放质量不是浓度。
- 合计未拆分、浓度、去除量、目标值不得 CLASSIFIED；与总氮候选并存时在 `alternatives`
  互相说明。
